# v0.3.0

> 已废弃：多语言功能实际不可用，由 v0.3.1 起的修复线取代。

### 多语言支持
- 应用内中英文切换（跟随系统 + 手动覆盖）（不可用）
- Android 13+ 系统设置中可见应用语言选项
- 全部 UI 字符串外部化，为更多语言做准备

### 多单位系统
- 完整公制/英制切换：km/h-mph、km-mi、C-F
- 车速表量程联动（240 km/h 与 160 mph），实时换算无需重启

### Android 风格层级设置
- 一级列表页 + 二级详情页：蓝牙与车辆 / 显示与外观 / 单位 / 语言 / 关于
- 列表页实时显示当前值（配对状态 / 主题 / 单位 / 语言）

### VIN 安全
- 配对后 VIN 输入锁定只读，后 6 位以 * 掩码
- 解绑后可再次编辑

### 其他
- 版本号升级至 0.3.0
