# v0.3.1

> 已废弃：仍无法在目标设备生效，由 v0.3.2 取代。

### 修复：应用内语言切换现在可靠工作
根因：过度依赖 `AppCompatDelegate.setApplicationLocales` 的隐式 Activity 重建（应用使用 Material3 主题，语言监听器中的任何异常都会静默中断整个链路）。以可靠机制重建：

- `LanguageManager` 维护内存语言缓存，`setLanguage()` 同步持久化 + 应用 + 更新缓存
- 每个 Activity 在 `attachBaseContext` 通过 `createConfigurationContext` 应用语言（不依赖主题/库行为）
- 切换语言触发当前页面显式 `recreate()`；冷启动首帧前也应用已存语言
- 语言监听器异常安全（不会再次静默死亡）

### 验证
- `values-en` 资源确认打包（aapt: locales 'en'）
- 全部 159 个字符串键双语齐全
- Release 构建通过

### 保留完整 v0.3.0 功能
