# v0.3.2

### 修复：语言选择现在每次点击都有响应
上一版本静默丢弃点击，因为点击处理依赖表单填充标志（`isFormPopulated`），该标志仅在 DataStore 流发出后才设置；若该发出延迟或失败，所有点击均被忽略——与"选择任意语言无反应"的报告吻合。重建后流程不再受此影响：

- 点击处理不再依赖表单填充标志；改用内存语言缓存比对，点击总是生效
- 语言缓存改为静态字段，在每个 Activity 的 `attachBaseContext` 直接读取（无 Hilt 注入时序依赖，任何顺序均可）
- 单选按钮改为直接点击监听，而非 RadioGroup 回调（不受程序化 `check()` 干扰）
- 切换失败通过可见 Toast + logcat（`LangDebug` 标签）提示，不再静默失败
- 每一步添加诊断日志（`LangDebug`），若仍有问题可快速定位

### 若仍失败请协助
安装本 APK 复现问题后运行：
```
adb logcat -s LangDebug
```
并分享输出。

- 公制/英制单位实时换算
