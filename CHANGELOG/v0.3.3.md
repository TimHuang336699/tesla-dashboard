# v0.3.3

### 新增：导出诊断日志（无需 adb）
- 所有关键路径（应用启动、语言保存/应用、`setApplicationLocales`、每个 Activity 的 `attachBaseContext`）记录到内存环形缓冲区（`AppLog`）
- 在 **设置 → 关于** 中点击 **"导出诊断日志"** → 系统分享面板 → 发送给自己（微信文件传输、邮件等）
- 日志包含：应用版本、设备型号、系统语言、当前语言缓存、带时间戳的每个语言切换步骤

### 如何协助修复
1. 安装本 APK（0.3.3）
2. 打开 设置 → 语言，点击 English（或任意语言），观察结果
3. 打开 设置 → 关于 → **导出诊断日志**，将文件发送给我们
4. 也可尝试：杀掉应用后重新打开，再导出一次（以捕获启动行为）

### 保留完整 v0.3.0 功能
- 应用内中英文切换（跟随系统 + 手动覆盖）
- 公制/英制单位实时换算
- Android 风格层级设置页
- 配对后 VIN 掩码
