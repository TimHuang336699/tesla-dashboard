# v0.3.4

### 已从用户导出的日志确认根因
诊断日志显示真实原因：该华为设备（NOH-AN00，Android 11）系统语言为 `en_CN`——英文语言 + 中国地区码，由设备多语言包设置产生。应用正确应用了 `zh`（`setApplicationLocales applied=zh`，无异常），但 Activity 仍渲染英文，因为仅靠 `createConfigurationContext` 在 EMUI 类 ROM 上不可靠：系统 `en_CN` 语言环境在资源解析中始终优先，导致选中 `values-en`。

### v0.3.4 修复内容
- **`applyOverrideConfiguration` 回退**：每个 Activity 的 `attachBaseContext` 中增加——华为/EMUI ROM 上应用语言的经典、经厂商验证的机制（必须在 `super.attachBaseContext` 之前执行）；与 `createConfigurationContext` 叠加使用
- **显式 `values-zh` 资源目录**：中文成为一等语言资源（APK 语言现为 `--_-- 'en' 'zh'`），不再依赖默认回退，消除多语言环境歧义
- **仅按语言代码应用**（`Locale("zh")`），不受 `en_CN` 等组合标签影响
- **移除语言页等语言守卫**：点击任意语言总是保存 + 重建，点击必有可见反馈
- **运行时语言校验日志**：`AttachBase` 记录每个 Activity 实际解析的语言，新导出的日志可确认回退是否真正生效

### 验证步骤
1. 安装 0.3.4
2. 设置 → 语言 → 点击 English / 中文
3. 设置 → 关于 → 导出诊断日志，检查 `AttachBase` 行：`actualLocale` 应显示与选择一致的 `zh` 或 `en`
4. 若 `actualLocale` 仍显示 `en_CN` 派生值，请分享日志——导出机制已就位，用于定位剩余层级
