# v0.3.5

### 新 Logo：狐小d 风格狐狸，标志性大小眼
- 暖橙色狐狸脸、内耳、白色口鼻、腮红
- **标志性大小眼**：左大右小（狐小d 造型）
- 深藏青底色（#1B1B2E），与车速表表盘颜色一致
- 兼容所有 API 26+ 启动器的自适应图标（圆形 + 圆角方形遮罩）

### 新增：1 秒启动动画
- 新增 `SplashActivity` 作为启动入口，展示狐狸 Logo 约 1 秒后进入仪表盘
- 动画：Logo 淡入 + 轻微放大 + **两只眼睛依次眨眼**（AnimatedVectorDrawable）
- Android 12+（API 31+）系统 SplashScreen 使用同一动画狐狸图标（values-v31 自定义主题）；Android 11 及以下使用自定义启动页播放动画

### 保留 v0.3.x 全部功能
- 应用内中英文切换（含多语言 ROM 修复）
- 公制/英制单位实时换算
- 层级化设置 + VIN 掩码
- 应用内诊断日志导出（设置 → 关于）
