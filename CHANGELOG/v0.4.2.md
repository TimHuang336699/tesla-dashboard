# v0.4.2

## BLE 连接优化

- **自适应轮询间隔**：行驶中 2.5s / 静止 5s——以车速、档位、功率综合判断行驶状态，静止更省电，行驶数据更流畅
- **消息超时重发**：会话握手与车辆状态请求超时后自动重发 1 次（counter 单调递增，协议安全），降低单包丢失导致的轮询失败
- **失败退避重连**：连续失败时轮询间隔指数退避（10s → 20s → 30s 封顶），成功立即恢复 5s，避免无效空转耗电
- **断开原因诊断**：异常断开（超时 / 远端断开 / 认证失败 / 链路丢失等）记录到应用内诊断日志，写特征失败一并记录
- **数据失效保护**：单次轮询失败不再清空仪表盘数值——保留上次有效数据并降透明度展示，状态栏提示"数据过期"

## 新功能

- **瞬时功率显示**：详情区新增功率（kW，动能回收为负值；英制单位自动换算为 hp），车辆实时驱动/回收功率一目了然
