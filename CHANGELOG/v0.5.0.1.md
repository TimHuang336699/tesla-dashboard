# v0.5.0.1

## 转向灯重绘

- **实心方块箭头**：使用 VectorDrawable 资源绘制（矩形柄 + 三角头），替换之前的 Canvas 矢量图
- **扫描动画**：从柄尾向尖端依次点亮（3 段），支持左转/右转/双闪
- **布局优化**：箭头分布在屏幕两侧，间距调整

## 设置页扩展

- **数据设置**：GNSS 降级开关、刷新频率、自动记录行程、数据源优先级
- **通知设置**：低电量、充电状态、温度异常、车门未关提醒
- **安全设置**：控制命令确认、自动锁车、NFC 身份验证
- **高级设置**：调试模式、重置设置、清除缓存、导出原始数据
- **滚动支持**：设置页添加 ScrollView，支持滚动浏览所有设置项

## 性能优化

- **R8 代码压缩**：启用 Minify 和资源压缩，APK 体积 5.7MB → 2MB（-65%）
- **CarSilhouetteView**：缓存 RectF 对象，避免 onDraw 中频繁分配内存
- **SpeedDisplayView**：缓存文本测量和字号计算，减少重复计算
- **DashboardActivity**：缓存常用字符串资源，减少 getString 调用
- **G-force 文本**：使用 StringBuilder 复用，避免每次分配

## Bug 修复

- 设置页无法滚动（缺少 ScrollView）
- 修复中文硬编码字符串，补充英文翻译
- 锁按钮直接切换解锁/锁定（移除选项弹窗）

## 界面调整

- 移除前后备箱控制，锁按钮仅保留解锁/锁定功能
