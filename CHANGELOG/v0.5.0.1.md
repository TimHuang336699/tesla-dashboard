# v0.5.0.1

## 转向灯重绘

- **实心方块箭头**：使用 VectorDrawable 资源绘制（矩形柄 + 三角头），替换之前的 Canvas 矢量图
- **扫描动画**：从柄尾向尖端依次点亮（3 段），支持左转/右转/双闪
- **布局优化**：箭头分布在屏幕两侧，间距调整

## 设置页扩展

- **数据设置**：GNSS 降级开关、刷新频率、自动记录行程、数据源优先级
- **通知设置**：低电量、充电状态、温度异常、车门未关提醒
- **安全设置**：控制命令确认、自动锁车、NFC 身份验证
- **高级设置**：调试模式、重置设置、清除缓存、导出原始数据
- **滚动支持**：设置页添加 ScrollView，支持滚动浏览所有设置项

## Bug 修复

- 设置页无法滚动（缺少 ScrollView）
