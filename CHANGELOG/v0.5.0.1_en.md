# v0.5.0.1

## Turn Signal Redesign

- **Solid Block Arrows**: Drawn with VectorDrawable resources (rectangular shaft + triangle head), replacing previous Canvas vector graphics
- **Scan Animation**: Lights up sequentially from shaft tail to tip (3 segments), supports left/right/hazard
- **Layout Optimization**: Arrows distributed on both sides of the screen with adjusted spacing

## Settings Page Expansion

- **Data Settings**: GNSS fallback toggle, refresh rate, auto trip recording, data source priority
- **Notification Settings**: Low battery, charging status, temperature anomaly, door open alerts
- **Security Settings**: Control command confirmation, auto lock, NFC authentication
- **Advanced Settings**: Debug mode, reset settings, clear cache, export raw data
- **Scroll Support**: Added ScrollView to settings page for scrolling through all settings

## Performance Optimization

- **R8 Code Minification**: Enabled Minify and resource shrinking, APK size 5.7MB → 2MB (-65%)
- **CarSilhouetteView**: Cache RectF objects to avoid frequent memory allocation in onDraw
- **SpeedDisplayView**: Cache text measurements and font size calculations to reduce redundant computation
- **DashboardActivity**: Cache common string resources to reduce getString calls
- **G-force Text**: Reuse StringBuilder to avoid allocation on every frame

## Bug Fixes

- Settings page not scrollable (missing ScrollView)
- Fixed hardcoded Chinese strings, added English translations
- Lock button directly toggles lock/unlock (removed options dialog)

## UI Changes

- Removed frunk/trunk controls, lock button only keeps unlock/lock function
