# v0.5.0

## GNSS 降级数据源

- **BLE 断开自动降级**：BLE 轮询失败/断开时自动启用手机 GNSS 定位（1s 更新），提供车速/位置/航向/海拔，仪表盘不空白
- **行程里程不中断**：BLE 时段由里程表差值累计，GNSS 时段以"BLE 基线 + GNSS 增量"续接，双向切换无重复无断档
- **智能启停省电**：降级开关跟随 BLE 可用性实时切换（flatMapLatest），BLE 恢复立即停用定位
- **数据来源提示**：状态栏显示"手机定位 (BLE 降级)"，位置/航向在降级期间正常展示

## 车辆控制

- **BLE 直连控制命令**：解锁 / 闭锁 / 打开前备箱 / 打开后备箱，经 VCSEC 域加密通道发送（唤醒 → 命令 → CommandStatus 校验）
- **控制面板**：仪表盘底部新增控制按钮，弹窗选择命令，结果 Toast 提示
- **会话互斥**：轮询与控制命令整段 BLE 会话串行化（Mutex），避免互相打断

## 转向灯指示 2.0

- **Material Design 实心三角形**：基于 Material Design Icons (menu-left/menu-right) 标准图标，等腰三角形，左右完全对称
- **特斯拉风格顺序扫描动画**：箭头分 3 段，亮起脉冲从根部向尖端流动（750ms 周期），支持左转/右转/双闪
- **主题色联动 + 设置开关**：激活色随主题切换，外观设置新增"转向灯指示"开关（默认开）

## 界面改进

- **温度常驻顶栏**：车内/车外温度固定显示在档位旁（无需展开详情区）
- **功率常驻主界面**：瞬时功率固定显示在车辆剪影下方（正=驱动 / 负=动能回收）
- **设置页扩展**：新增数据、通知、安全、高级 4 个设置大项（共 8 组 18 项）
  - 数据：GNSS 降级开关、刷新频率、自动记录行程、数据源优先级
  - 通知：低电量、充电状态、温度异常、车门未关提醒
  - 安全：控制命令确认、自动锁车、NFC 身份验证
  - 高级：调试模式、重置设置、清除缓存、导出原始数据

## Bug 修复

- **GNSS 降级永不生效**：数据流仅在启动时检查一次开关，改为流内实时响应开关变化
- **Activity 重建后降级失效**：仓库 stop() 不再取消常驻作用域，start() 可重复重建跟踪任务
- **BLE 会话互相打断**：轮询与控制命令共享会话互斥锁
