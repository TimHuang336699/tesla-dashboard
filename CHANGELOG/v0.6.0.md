# CHANGELOG

[中文](CHANGELOG.md)

## v0.6.0

### BLE 指令安全代理
- **BleCommandProxy**: 插件 BLE 指令强制入口, 抽象发送通道, 独立可测
- **指令白名单**: 风险分级注册, 只读/低风险直接放行; 高风险指令需用户确认
- **用户确认机制**: 确认回调调用前通知, 记录请求来源; 支持会话内取消注册
- **统一结果模型**: Success / Rejected (永不发送) / VehicleError / Failed
- **冲突指令串行化**: 冲突指令严格串行执行, 高优先级插队, 防并发覆盖

### APK 插件沙箱
- **DexClassLoader + 独立 ClassLoader**: 插件无法访问宿主内部类, 仅接触 DashboardPlugin 接口
- **manifest meta-data 声明入口类**: 反射实例化
- **错误分类**: SignatureRejected / LoadFailed

### 插件签名验证
- **SHA-256 指纹**: 兼容 v1/v2/v3 签名方案
- **三级策略**: 白名单 → Trusted / 自签名 → 需要用户确认 / 异常 → 拒绝

### PluginContext API 增强
- **PluginEventBus**: 插件间类型化事件发布订阅, 多订阅者, 取消订阅, 历史回放, 活跃订阅统计

### 运行时异常边界隔离
- **PluginBoundary隔离**: 插件异常隔离不泄漏到宿主, 隔离错误处理器捕获并记录

### 安全
- 指令代理/调度/沙箱/签名全链路单元测试覆盖 (纯 JVM)
- AppLog 测试环境自动降级, 生产行为不变

### 工程化
- 版本号 0.6.0 (versionCode = 21)
- 新增 18 个单元测试全绿 (BleCommandProxyTest, BleCommandRegistryTest, ApkSignatureVerifierTest, PluginEventBusTest)
