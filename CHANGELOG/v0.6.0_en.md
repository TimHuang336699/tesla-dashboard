## v0.6.0

### BLE Command Proxy (Security)
- **BleCommandProxy**: mandatory gateway for all plugin BLE commands, testable send abstraction
- **Risk-classified whitelist**: read-only/low-risk pass through; high-risk (unlock/AC/charging) need user confirmation
- **Unified result model**: Success / Rejected (never sent) / VehicleError / Failed
- **Conflicting-command serialization**: strictly serial execution of conflicting commands, high-priority queue-jump (non-preemptive)

### APK Plugin Sandbox
- **DexClassLoader with isolated ClassLoader**: plugins cannot reach host internals
- **Manifest meta-data entry**: instantiated via reflection
- **Error taxonomy**: SignatureRejected / LoadFailed

### Plugin Signature Verification
- **SHA-256 fingerprints**: compatible with signing schemes v1/v2/v3
- **Three-tier policy**: whitelisted → Trusted; self-signed → user confirmation; abnormal → refused

### PluginContext API Enhancements
- **PluginEventBus**: typed event pub/sub between plugins, multi-subscriber, unsubscribe, history replay

### Runtime Exception Boundary Isolation
- **PluginBoundary isolation**: plugin exceptions don't leak to host, isolated error handler captures and logs

### Security
- Full unit-test coverage of entire security chain (proxy/scheduler/sandbox/signature), pure JVM, no Android dependencies
- AppLog gracefully degrades in test environments; production behavior unchanged

### Engineering
- Version 0.6.0 (versionCode = 21)
- 18 new unit tests all green (BleCommandProxyTest, BleCommandRegistryTest, ApkSignatureVerifierTest, PluginEventBusTest)
