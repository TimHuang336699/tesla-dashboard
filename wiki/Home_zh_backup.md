## What is Tesla Dashboard?

Tesla Dashboard is a native Android application that turns your device into a real-time vehicle dashboard for Tesla cars. It connects directly to the vehicle over **Bluetooth Low Energy (BLE)** — no cloud API, no subscription — and delivers an Apple-inspired minimalist dashboard with live driving data.

## Key Features

- **BLE Direct Connection** — Implements Tesla's vehicle-command BLE protocol
- **Real-time Data** — Speed, battery, temperature, position, G-force
- **Vehicle Control** — Unlock/lock via BLE
- **GNSS Fallback** — Automatic phone GPS when BLE disconnects
- **11 Themes** — Dark/Light + accent colors, live switching
- **Multi-language** — 中文 / English
- **Multi-unit** — Metric / Imperial
